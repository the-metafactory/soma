# Analysis is read-only

**When it applies:** the request says analyze, review, assess, investigate, explain, or "create a plan".

**Rule:** produce the report or the plan, then stop. No file, branch or tracker changes until the principal asks for them.

- "Fix", "refactor", "update", "build" allow modifications; "review" never does.
- A plan is presented and waits for approval. Executing it is a new request.

You skipped this when an analysis request ends with a diff.
