# Encode lessons in structure

**When it applies:** you write the same instruction a second time, or the same correction recurs.

**Rule:** encode the lesson as structure (a test, a lint, a gate, a schema, a hook, a script) instead of more text. The repeated instruction is the symptom.

- If the fix is structural, ship only the structural fix; do not also restate it in prose.
- If the lesson needs judgment and cannot be encoded, make the instruction more prominent and add an example of the failure it prevents.
- In Soma, where the structure lands follows the SelfHealing routing: a recurring preference to a projected rule, a process miss to a criterion or a nudge, a code failure to a test obligation.

You skipped this when a doc, memory or prompt gains a rule that a check could enforce.
