# Change only what was asked

**When it applies:** the work touches code or text, and you notice something adjacent you could improve.

**Rule:** the diff holds the ask. Adjacent improvements become a note, a follow-up node or a question, not an edit.

- Never modify a working feature unprompted.
- A refactor that rides along with a fix makes the fix harder to review and to revert.

You skipped this when the diff contains a hunk the request does not explain.
